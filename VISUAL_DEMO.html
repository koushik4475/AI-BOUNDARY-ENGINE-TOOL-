🎯 Real-World Integration Example

from boundary_engine import BoundaryEngine, Decision

engine = BoundaryEngine()

def safe_chatbot(user_message):
    # Check safety BEFORE calling LLM
    boundary = engine.analyze(user_message)
    
    if boundary.decision == Decision.REFUSE:
        return "I cannot help with that request."
    
    if boundary.decision == Decision.CLARIFY:
        return f"Please clarify: {boundary.reasons[0]}"
    
    # Safe to proceed with LLM
    return your_llm.complete(user_message)

# Example usage:
safe_chatbot("How to make a bomb")
# Output: "I cannot help with that request." ✅

safe_chatbot("What is machine learning?")
# Output: [LLM provides educational response] ✅
This is where it's useful: Add as a safety layer before ANY LLM (GPT, Claude, Llama). It acts as a firewall, blocking harmful requests before they reach your AI.
